## Notenschlüssel und Rohpunkte für Klassenarbeiten

Bei einem Leistungsnachweis Punkte statt Noten eintragen, die Note ergibt sich aus einem einstellbaren Notenschlüssel (Prozentgrenzen je Note, als Vorlage speicherbar). War schon im Grilling als „später“ vorgemerkt.

## Datenschutz-Seite für die Schulleitung

In Niedersachsen braucht die Verarbeitung von Schülerdaten auf einem privaten Gerät die Genehmigung der Schulleitung. Eine kurze Seite in der App (auch druckbar) erklärt: welche Daten gespeichert werden, dass sie nur auf dem Gerät liegen, wie die Sicherung verschlüsselt ist (AES-256, Passwort), dass nichts an einen Server geht und dass das iPad einen Code braucht.

Dazu passend: ein Modus „Markierungen verbergen“, falls das iPad an den Beamer gespiegelt wird.
