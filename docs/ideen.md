# Ideen für später

Vorschläge aus dem Review vom 23.10.2026, noch nicht umgesetzt. Reihenfolge = vorgeschlagene Priorität.

## Anzahl der Stunden hinter einer Note zeigen

In der Notenübersicht sieht eine Mündliche Note aus 4 Stunden genauso sicher aus wie eine aus 30. Pro Schüler die Zahl der gewerteten Stunden anzeigen, dazu die Verteilung (++ / + / ○ / − / −−). Hilft bei Grenzfällen und im Elterngespräch und macht sichtbar, dass stille Schüler durch die Vorbelegung ○ Richtung 3 wandern.

## Notizen pro Schüler

Freitext zu einem Schüler in einer Lerngruppe (Elterngespräch, Förderplan, Absprachen), mit Datum. Erscheint im Schülerbericht. Fließt nie in die Note ein.

## Lerngruppe ins neue Schuljahr übernehmen

Bisher gibt es am Schuljahresende nur „Archivieren“; im August müsste jede Lerngruppe neu angelegt werden. Ein Knopf „Ins neue Schuljahr übernehmen“ legt eine neue Lerngruppe an mit denselben Schülern, demselben Sitzplan, denselben Notenbereichen und Verhaltenskategorien, aber ohne Stunden, Beobachtungen und Leistungsnachweise. Die alte wird archiviert.

## Notenschlüssel und Rohpunkte für Klassenarbeiten

Bei einem Leistungsnachweis Punkte statt Noten eintragen, die Note ergibt sich aus einem einstellbaren Notenschlüssel (Prozentgrenzen je Note, als Vorlage speicherbar). War schon im Grilling als „später“ vorgemerkt.

## Datenschutz-Seite für die Schulleitung

In Niedersachsen braucht die Verarbeitung von Schülerdaten auf einem privaten Gerät die Genehmigung der Schulleitung. Eine kurze Seite in der App (auch druckbar) erklärt: welche Daten gespeichert werden, dass sie nur auf dem Gerät liegen, wie die Sicherung verschlüsselt ist (AES-256, Passwort), dass nichts an einen Server geht und dass das iPad einen Code braucht.

Dazu passend: ein Modus „Markierungen verbergen“, falls das iPad an den Beamer gespiegelt wird.
